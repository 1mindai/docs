Some Microsoft tenants do not let users approve third-party apps for themselves. In those tenants, the first rep to connect Outlook sends an approval request for the **1mind Scheduling** app to the company's Microsoft admin, and every rep's connection waits on that one approval.

This is a Microsoft tenant setting, **not** an SSO problem.

## What the rep sees

When the rep connects Outlook in **Profile → Scheduling and meetings**, Microsoft shows an access-request message instead of completing the connection, and routes the request to the company's Microsoft admin. The rep cannot approve it themselves.

## How the Microsoft admin approves

A Microsoft admin approves once for the whole tenant:

1. Open the **Entra admin center**.
2. Go to **Enterprise applications → Admin consent requests**.
3. Approve the request for the **1mind Scheduling** app.

After that, every rep in the tenant can connect Outlook.

An admin can clear this up front by connecting their own calendar first, which triggers and lets them approve the request before reps hit it.

<Note>
An admin cannot connect calendars on a rep's behalf. Connections are per rep. Some Microsoft tenants simply need this one-time approval before reps can connect.
</Note>
