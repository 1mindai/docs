## 4. Web Superhuman integration & visitor matching

To match website visitors to CRM/MAP records, 1mind needs web tracking via
cookies, session IDs, or other mechanisms.

- **Tracking methods:** cookies, local storage, session ID.
- **Required data points:** visitor IP; CRM/MAP user identifier (hashed if needed); user session ID; IP-to-company data (ZoomInfo, 6sense, Clearbit, RB2B).
- **Integration steps:** (1) embed the launcher script (see [Website embed & script installation](/configuring/integrations/website-embed)); (2) capture the visitor identifier and map to CRM/MAP; (3) sync session variables to the launcher to enrich the Superhuman dialog.
- **Customer action item:** provide developer resources for web implementation.

## 5. Testing & deployment plan

1. **Initial data validation** — validate CRM & MAP ingestion; confirm field mappings.
2. **Web tracking validation** — verify visitor-ID resolution and session persistence.
3. **Superhuman integration testing** — preload test data, run mock conversations, verify logs and CRM/MAP updates.
4. **Production deployment** — migrate tested integrations, monitor live sync, provide hypercare.

**Customer action items:** conduct UAT, assign technical leads for monitoring,
schedule periodic post-launch reviews.
