# Pre & Post Processing

*Last updated July 29, 2025*

# PRE-PROCESSING (READ ACCESS)

## Purpose

Load existing customer and lead data into superhuman conversations for personalization and context.

### **Salesforce Objects - READ ACCESS**

- Lead - Contact info, qualification status, lead source, company details
- Contact - Personal details, account association, engagement history
- Account - Company information, industry, size, existing relationships
- Opportunity - Active deals, product interest, sales stage
- Custom Objects - Qualification criteria, product ownership, activity history

### **Marketo Objects - READ ACCESS**

- Persons - Lead/prospect data, engagement scores, behavioral data
- Programs - Campaign membership, program status, engagement history
- Activities - Website visits, email interactions, content downloads
- Custom Objects - Segmentation data, nurture campaign status

### **Third-Party Data Sources - READ ACCESS**

- ZoomInfo/Demandbase/6sense - Browser cookies or local cache data for company firmographics and intent data
- Website Data Layer - URL parameters and website variables injected into 1mind's launcher JavaScript

### **Key Pre-Processing Data Points**

- Existing product ownership
- Recent activity and engagement
- Company size and industry
- BANT qualification status
- Marketing program membership
- Website behavioral data

# POST-PROCESSING (WRITE ACCESS)

### **Purpose**

Push conversation outcomes, insights, and qualification data back to business systems.

### **Salesforce Objects - WRITE ACCESS**

- Lead - Update qualification status, conversation summaries, BANT criteria
- Contact - Add conversation notes, update engagement data
- Account - Update company insights, engagement history
- Opportunity - Create new opportunities, update existing deal information
- Task - Create follow-up tasks, log conversation activities, set reminders
- Custom Objects - Log superhuman interactions, qualification scores

### **Marketo Objects - WRITE ACCESS**

- Persons - Update lead scores, conversation engagement, qualification status
- Programs - Enroll in nurture campaigns based on conversation topics
- Custom Activities - Log superhuman interactions, conversation summaries
- Custom Objects - Update segmentation data, campaign triggers

### **Key Post-Processing Data Points**

- Qualification Data: BANT criteria, SQL status, decision-maker identification
- Conversation Insights: Key topics discussed, pain points identified, product interest
- Campaign Attribution: Source tracking, demand generation attribution
- Nurture Triggers: Topic-based segmentation, communication preferences
- Sales Handoff: Conversation transcripts, next steps, contact preferences

### **Post-Processing Actions**

1. Qualified Leads: Update lead status, assign to sales rep, trigger sales alerts
2. Nurture Campaigns: Segment leads into relevant tracks based on conversation topics
3. Reporting Data: Extract metrics for performance tracking and analytics
4. Data Warehouse: Export flat files for BI ingestion and custom reporting

## **Integration Methods**

- Authentication: OAuth 2.0 for Salesforce, API keys for Marketo
- APIs: REST APIs for real-time data exchange
- Webhooks: Event-driven updates for immediate processing
- Flat Files: Batch exports for data warehouse integration
