This is the running record of notable changes to the 1mind platform, new capabilities, meaningful improvements, and fixes that affect how you use the product.

## How this changelog works

- **Single current docs set plus this changelog.** The documentation always describes the latest version of 1mind; this page records what changed and when. Separate versioned doc trees are only introduced if a breaking-change cadence later requires it.
- **Cadence.** Notable changes are summarized here on a **monthly** basis, with significant launches noted as they ship. Each entry names the capability, what changed, and any action you need to take.
- **Where else updates appear.** Material updates are also shared through the customer Slack/Discord channels; this page remains the durable record.
